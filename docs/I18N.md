# Aura Video AI — Internationalization (i18n)

## Supported (enabled)
| Code | Name | Direction |
|------|------|-----------|
| en | English | ltr |
| fr | Français | ltr |
| ar | العربية | rtl |

Additional languages are registered in `@aura/i18n` with `enabled: false` until dictionaries are added.

## Architecture
- **Package:** `packages/i18n` — language metadata + JSON dictionaries
- **Frontend:** `i18next` + `react-i18next`
- **Provider:** `LanguageProvider` / `useLanguage()`
- **Persistence:** `localStorage` key `aura_language`; DB column `users.preferred_language`
- **Document:** `document.documentElement.lang` + `dir` (rtl for ar)

## Language layers
1. `interfaceLanguage` — UI strings
2. `aiOutputLanguage` — assistant replies
3. `contentLanguage` — product analysis / creative
4. `videoLanguage` — script, captions, on-screen text, TTS

Default: all four follow the selected interface language.

## Adding a language
1. Add metadata in `packages/i18n/src/languages.ts` (`enabled: true`)
2. Add `packages/i18n/locales/{code}.json`
3. Register resource in `apps/web/src/i18n.ts`
4. No other architecture changes required

## Fallback
Missing key → English (`fallbackLng: en`).

## AI
API helpers: `languageSystemInstruction()` in `apps/api/src/modules/ai/utils/language-prompt.ts`.

## Errors
Backend returns stable codes (`VIDEO_GENERATION_FAILED`, …). Frontend maps via `errors.*` keys.
